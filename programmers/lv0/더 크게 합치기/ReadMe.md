----------------------------------------------------------------------------------------------------------------------------------------------------
[문제 설명]

연산 ⊕는 두 정수에 대한 연산으로 두 정수를 붙여서 쓴 값을 반환합니다. 예를 들면 다음과 같습니다.

12 ⊕ 3 = 123
3 ⊕ 12 = 312
양의 정수 a와 b가 주어졌을 때, a ⊕ b와 b ⊕ a 중 더 큰 값을 return 하는 solution 함수를 완성해 주세요.

단, a ⊕ b와 b ⊕ a가 같다면 a ⊕ b를 return 합니다.
----------------------------------------------------------------------------------------------------------------------------------------------------
[제한사항]

1 ≤ a, b < 10,000
----------------------------------------------------------------------------------------------------------------------------------------------------
[입출력 예]

a	b	result
9	91	991
89	8	898
----------------------------------------------------------------------------------------------------------------------------------------------------
[입출력 예 설명]

입출력 예 #1
a ⊕ b = 991 이고, b ⊕ a = 919 입니다. 둘 중 더 큰 값은 991 이므로 991을 return 합니다.

입출력 예 #2
a ⊕ b = 898 이고, b ⊕ a = 889 입니다. 둘 중 더 큰 값은 898 이므로 898을 return 합니다.
----------------------------------------------------------------------------------------------------------------------------------------------------
[풀이방법]

#1
class Solution {
    public int solution(int a, int b) {
        String s1 = a + "" + b;
        // int에 빈 문자열을 더하면 자동으로 String으로 변환됨
        String s2 = b + "" + a;
        // 반대의 경우도 확인해줌
        
        if(Long.parseLong(s1) >= Long.parseLong(s2)){
        // s1을 long 타입으로 변환해서 나타내줌
            return Integer.parseInt(s1);
            // 메서드의 return값이 int이므로 이 경우 Integer.parseInt를 사용해줌
        } else {
            return Integer.parseInt(s2);
        }
    }
}
----------------------------------------------------------------------------------------------------------------------------------------------------
[복습할 내용]

#1
Java 규칙: 숫자 + 문자열 = 문자열 (암기)

#2
int를 String으로 변환하는 방법
a + ""   →   9 + "" = "9"
int에 빈 문자열을 더하면 자동으로 String으로 변환됨
a + "" + b   →   9 + "" + 91 = "991" (두 숫자 이어붙이기)

#3
Long.parseLong(s)
문자열을 Long(숫자)으로 변환 — 크기 비교할 때 사용
Integer.parseInt 대신 Long 쓰는 이유:
붙인 숫자가 int 범위를 넘을 수 있어서 습관적으로 Long 사용

#4
Integer.parseInt(s)
문자열을 int로 변환
return 타입이 int일 때 문자열을 숫자로 바꿔서 반환할 때 사용
